# EEI6373-PerformanceModelling-MiniProject
EEI6373 Performance Modelling mini project – University Student Registration Queue

## Project Title

Performance Modelling of a University Student Registration Queue Under Varying Arrival Rates

## System

This project models a physical university student registration queue
with one registration officer.

## Performance Objectives

- Minimize student waiting time
- Maximize throughput
- Identify performance bottlenecks
- Analyze queue length
- Evaluate registration officer utilization

## Dataset

The project uses a synthetic dataset representing student arrivals
and registration service times under three workload scenarios:

- Normal – 10 students/hour
- High – 20 students/hour
- Peak – 25 students/hour

The dataset is used as the workload input for the performance
simulation.

## Project Structure

- `dataset/` – Synthetic simulation dataset
- `deliverable/` – Mini Project Deliverable document
- `analysis/` – Simulation and analysis files
